# AI Learning Journey: From Python to AI Agents

This repository serves as a comprehensive, step-by-step roadmap and collection of resources for mastering Artificial Intelligence, starting from basic Python programming and culminating in the development of autonomous AI Agents.

---

## 🗺️ Step-by-Step Learning Plan

### Phase 1: Python Programming Fundamentals
Before diving into AI, a strong foundation in Python is essential.
*   **Concepts:** Variables, Data Types, Loops, Conditionals, Functions, Object-Oriented Programming (OOP).
*   **Practical Example:** Build a simple calculator, a text-based to-do list, or a tic-tac-toe game in the terminal.
*   **Resources:**
    *   [Python Official Documentation](https://docs.python.org/3/tutorial/index.html)
    *   [Automate the Boring Stuff with Python](https://automatetheboringstuff.com/)

### Phase 2: Data Manipulation & Analysis
Learn how to handle, clean, and visualize data, which is the fuel for any AI model.
*   **Concepts:** Pandas (DataFrames), NumPy (Arrays), Matplotlib & Seaborn (Data Visualization).
*   **Practical Example:** Analyze a real-world dataset (e.g., Titanic passenger data or weather data) and create visualizations of trends.
*   **Resources:**
    *   [Kaggle Pandas Micro-Course](https://www.kaggle.com/learn/pandas)

### Phase 3: Machine Learning (ML) Foundations
Understand how machines learn from data without being explicitly programmed.
*   **Concepts:** Supervised Learning (Regression, Classification), Unsupervised Learning (Clustering), Scikit-Learn library, Model Evaluation (Accuracy, Precision, Recall).
*   **Practical Example:** Predict house prices based on features (Linear Regression) or classify emails as spam/not spam (Logistic Regression).
*   **Resources:**
    *   [Machine Learning section](https://github.com/gurvinder-02/ai-learning/blob/main/machine-learning/README.md)
    *   [Machine Learning by Andrew Ng (Coursera)](https://www.coursera.org/learn/machine-learning)

### Phase 4: Deep Learning (DL) & Neural Networks
Dive into algorithms inspired by the structure and function of the brain.
*   **Concepts:** Neural Networks, Activation Functions, Backpropagation, PyTorch or TensorFlow frameworks, Convolutional Neural Networks (CNNs) for images.
*   **Practical Example:** Build an image classifier to identify handwritten digits (MNIST dataset) or classify images of cats vs. dogs.
*   **Resources:**
    *   [Deep Learning section](https://github.com/gurvinder-02/ai-learning/blob/main/deep-learning/README.md)
    *   [Deep Learning Specialization by Andrew Ng (Coursera)](https://www.coursera.org/specializations/deep-learning)

### Phase 5: Natural Language Processing (NLP) & Large Language Models (LLMs)
Learn how machines understand and generate human language.
*   **Concepts:** Text processing, Embeddings, Transformers, Hugging Face `transformers` library, prompting LLMs (like GPT or Llama).
*   **Practical Example:** Build a sentiment analysis tool for movie reviews or a simple chatbot using a pre-trained Hugging Face model.
*   **Resources:**
    *   [Hugging Face NLP Course](https://huggingface.co/learn/nlp-course)

### Phase 6: Building AI Agents
Combine LLMs with tools and memory to create autonomous problem-solving agents.
*   **Concepts:** Agent architectures, Tool calling, Memory (Short-term/Long-term), Vector Databases (Chroma, Pinecone), LangChain or LlamaIndex frameworks.
*   **Practical Example:** Build a research agent that can search the web, read articles, and write a summary report autonomously.
*   **Resources:**
    *   [Artificial Intelligence section](https://github.com/gurvinder-02/ai-learning/blob/main/ai/README.md)
    *   [LangChain Documentation](https://python.langchain.com/docs/get_started/introduction)

## 🏗️ Project Ideas

Put your skills to the test with these progressive project ideas:

1.  **Beginner (Python + Data):** 
    *   **Personal Finance Tracker:** A CLI tool to log expenses and generate monthly charts.
2.  **Intermediate (Machine Learning):**
    *   **Movie Recommendation System:** Suggest movies to users based on their viewing history using Collaborative Filtering.
3.  **Advanced (Deep Learning & NLP):**
    *   **Document Summarizer Web App:** A simple web interface where users upload PDFs, and an LLM returns a concise summary.
4.  **Expert (AI Agents):**
    *   **Automated Customer Support Agent:** An agent that connects to a company's knowledge base (via a Vector DB) and can autonomously answer customer queries, routing complex ones to a human.
